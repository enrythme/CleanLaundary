# Химчистки и прачечные

Проект по учебной практике УП.01.01. Приложение для управления заказами сети химчисток и прачечных: C#, WPF, .NET 8 и PostgreSQL. Решение содержит один WPF-проект.

## Выполненная работа

Реализованы авторизация и регистрация с ролями пользователя и администратора, хэширование паролей, капча после трёх неверных попыток входа. Пользователь просматривает свои заказы и услуги, выполняет поиск, фильтрацию и сортировку. Администратор добавляет, изменяет и удаляет записи, просматривает диаграмму и экспортирует данные в DOCX, PDF и XLSX. Предусмотрены смена пароля, сохранение темы, проверки ввода, подсказки и подтверждение действий. Удаление связанных заказов каскадное.

## Структура решения

| Файлы и каталоги | Назначение |
| --- | --- |
| `LaundryPractice.sln`, `LaundryPractice.csproj` | Решение и WPF-проект |
| `*.xaml`, `*.xaml.cs` | Окна приложения и обработчики событий |

| `appsettings.example.json` | Образец настройки подключения |

## Запуск

1. На Windows открыть `LaundryPractice.sln` в Visual Studio 2022 с поддержкой WPF и .NET 8.
2. В pgAdmin 4 выполнить первую строку `db/schema.sql` в базе `postgres` с включённым Auto Commit. Остальную часть, начиная с `BEGIN;`, выполнить в новой базе `laundry_practice`.
3. Задать собственный пароль роли PostgreSQL `laundry_practice_app`. Скопировать `appsettings.example.json` в `appsettings.json` и заполнить строку подключения. Локальный файл настроек исключён из Git.
4. Зарегистрировать учётную запись в приложении. Для назначения администратора выполнить в Query Tool: `UPDATE users SET role='Admin' WHERE login='ваш_логин';` и войти заново.

Начальные пользователи служат примерами для демонстрационных заказов; действующие пароли в репозитории не хранятся. Для уже созданной локальной базы использовать свои существующие настройки и учётные записи.
